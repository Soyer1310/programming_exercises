сумма цифр числа
Теперь применим тот же принцип к задаче, которую ты уже решал с обычной рекурсией.
Реализуй sumDigits(n) с помощью итеративного процесса.
Примеры:
sumDigits(5); // 5
sumDigits(123); // 6
sumDigits(5831); // 17
sumDigits(9004); // 13

Условия:

- Используй внутреннюю рекурсивную функцию iter().
- Не используй циклы и методы массивов.
- Считай, что n — неотрицательное целое число.
- Не откладывай сложение цифр до возвращения из рекурсии.
  Подсказка по математике: последнюю цифру можно получить через n % 10, а отбросить её — через Math.floor(n / 10).
