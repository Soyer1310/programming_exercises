Рекурсивный поиск

Дан массив чисел. Реализуй функцию contains(numbers, target), которая возвращает true, если искомое число присутствует в массиве, и false в противном случае.

contains([4, 8, 15, 16, 23, 42], 15); // true
contains([4, 8, 15, 16, 23, 42], 7); // false
contains([], 5); // false

Условия:

Используй рекурсию.

Не используй includes(), indexOf(), циклы или методы перебора массивов.

Можешь добавить второй параметр index, если он тебе нужен.

Здесь важно правильно обработать пустой массив и момент, когда индекс выходит за границы.
