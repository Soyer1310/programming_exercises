Реализуй функцию, возвращающую массив имён совершеннолетних пользователей.
На вход подаётся массив типа:

const users = [
{ name: 'Artem', age: 35 },
{ name: 'John', age: 20 },
{ name: 'Mike', age: 17 },
];

Нужно получить имена совершеннолетних пользователей.
Требование:

Как ты реализуешь это так, чтобы функция была запросом (в соответствии с принципом CQS разделения команд и запросов), а исходный users не изменялся?

Ожидаемый результат:

['Artem', 'John']
