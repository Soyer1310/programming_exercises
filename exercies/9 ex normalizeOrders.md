Нормализация заказов

Представим, что сервер возвращает список заказов в неоднородном виде: какие-то поля отсутствуют, цены хранятся строками, а статусы записаны в разном регистре.

const orders = [
{
id: 101,
customer: { firstName: ' anna', lastName: 'IVANOVA ' },
items: [
{ name: 'Keyboard', price: '100', quantity: 1 },
{ name: 'Mouse', price: '50', quantity: 2 },
],
status: 'PAID',
},
{
id: 102,
customer: { firstName: 'PAVEL', lastName: ' petrov' },
items: [
{ name: 'Monitor', price: '300', quantity: 1 },
],
status: 'pending',
},
{
id: 103,
customer: { firstName: 'Maria', lastName: 'Sidorova' },
items: [],
status: 'CANCELLED',
},
];

Нужно получить новый массив объектов такого формата:

[
{
id: 101,
customerName: 'Anna Ivanova',
total: 200,
status: 'paid',
isPaid: true,
itemNames: ['Keyboard', 'Mouse'],
},
// ... остальные заказы в таком же формате
]
Требования

Используй map() для преобразования массива заказов. Каждый заказ должен превратиться в новый объект.

customerName должен содержать имя и фамилию с заглавной первой буквой, остальные буквы — строчные. Лишние пробелы по краям необходимо убрать.

total — сумма стоимости всех товаров с учётом количества. Цена из исходных данных приходит строкой.

status приведи к нижнему регистру.

isPaid должен быть true, только если исходный статус равен PAID без учёта регистра.

itemNames — массив названий товаров в исходном порядке. Для этого поля тоже используй map().

Не изменяй исходный массив orders и вложенные в него объекты.

Дополнительная проверка: заказ № 103 не содержит товаров. Подумай, каким должен быть его total, и убедись, что твой код работает с пустым массивом items.

Можешь создавать вспомогательные функции — например, для нормализации имени. В этом задании важен не только итог, но и то, как ты организуешь преобразования.
