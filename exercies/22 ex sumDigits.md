Сумма цифр числа

Напиши рекурсивную функцию sumDigits(n), которая возвращает сумму цифр неотрицательного целого числа.

Примеры:

sumDigits(0); // 0
sumDigits(7); // 7
sumDigits(1234); // 10
sumDigits(905); // 14

Условия:

Не используй циклы.

Не преобразовывай число в строку.

Используй арифметические операции % и Math.floor().

Обработай базовый случай.
