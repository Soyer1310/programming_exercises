Напиши рекурсивную функцию countOccurrences(numbers, target), которая считает, сколько раз число встречается в массиве.

countOccurrences([1, 2, 1, 3, 1], 1); // 3
countOccurrences([5, 5, 5], 5); // 3
countOccurrences([1, 2, 3], 9); // 0
countOccurrences([], 1); // 0

Условия:

Используй рекурсию.

Не используй циклы и методы перебора массивов.

Не изменяй исходный массив.

Можно использовать деструктуризацию, как в предыдущем решении, либо индекс.

Подумай, что должна вернуть функция, когда массив пуст, и как результат текущего шага складывается с результатом рекурсивного вызова.
