Сумма чисел во вложенном массиве

Напиши функцию sumNested(numbers), которая возвращает сумму всех чисел во вложенном массиве любой глубины.

Примеры:

sumNested([1, 2, 3]); // 6
sumNested([1, [2, 3], 4]); // 10
sumNested([1, [2, [3, 4]], 5]); // 15
sumNested([[], [1, [2, []]], 3]); // 6
sumNested([]); // 0

Условия:

Используй рекурсию.

Не используй циклы, map(), filter(), reduce() или flat().

Не изменяй исходный массив.

Можно использовать вспомогательную рекурсивную функцию.

Предполагается, что массив содержит только числа и другие массивы.

На что обратить внимание

В предыдущей задаче каждый элемент был числом. Теперь элемент может оказаться как числом, так и массивом.

Например, в массиве [1, [2, 3], 4] число 1 можно прибавить напрямую, а элемент [2, 3] потребует отдельной обработки.
