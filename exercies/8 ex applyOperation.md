Создай собственную функцию высшего порядка

Напиши функцию applyOperation, которая принимает три аргумента:

a — первое число;

b — второе число;

operation — функция, которая определяет операцию над числами.

Внутри applyOperation необходимо вызвать operation, передав ей числа a и b, и вернуть результат.

Затем создай две функции-колбека:

add — складывает числа;

multiply — умножает числа.

Пример ожидаемого поведения:

applyOperation(4, 5, add); // 9
applyOperation(4, 5, multiply); // 20

Главное условие: не реализуй сложение и умножение внутри applyOperation. Её задача — вызвать переданную функцию.
