рекурсивное преобразование вложенного массива

Теперь изменим тип задачи. До этого мы вычисляли одно итоговое значение — сумму или максимум. Теперь нужно создать новый массив той же структуры, в котором каждое число умножено на два.

Например:

doubleNested([1, [2, 3], 4]);
// [2, [4, 6], 8]

doubleNested([1, [2, [3, 4]], 5]);
// [2, [4, [6, 8]], 10]

doubleNested([]);
// []

Условия:

Используй рекурсию.

Не используй циклы, map(), flat() или reduce().

Не изменяй исходный массив.

Сохраняй всю структуру вложенности.

Каждый вложенный массив в результате должен быть новым массивом.

Подумай, как совместить два случая: если текущий элемент — число, нужно умножить его на два; если массив — рекурсивно преобразовать его содержимое.
