поиск максимального числа во вложенном массиве

Теперь используй тот же принцип, но вместо суммы найди максимальное число.

findMaxNested([1, [8, [3, 12]], 5]); // 12
findMaxNested([[-10, -3], [-7]]); // -3
findMaxNested([4]); // 4

Условия:

Только рекурсия — без циклов и методов перебора.

Не изменяй исходный массив.

Массив гарантированно содержит хотя бы одно число.

Вложенность может быть любой глубины.

Важный нюанс: для суммы пустой массив возвращает 0, а для максимума это правило не подходит. Например, если все числа отрицательные, начальное значение 0 ошибочно окажется больше любого элемента.
