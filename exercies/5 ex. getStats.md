Сумма и количество аргументов

Напиши функцию getStats, которая принимает любое количество чисел и возвращает объект с двумя свойствами:

sum — сумма всех переданных чисел;

count — количество переданных чисел.

Примеры:

getStats(2, 5, 3);
// { sum: 10, count: 3 }

getStats(10, -4);
// { sum: 6, count: 2 }

getStats();
// { sum: 0, count: 0 }

Условия:

Используй rest-оператор.

Не используй arguments.

Не используй методы reduce, filter и map: пока реши задачу обычным циклом for...of.
