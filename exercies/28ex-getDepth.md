Напиши функцию getDepth(numbers), которая возвращает максимальную глубину вложенности массива.

Правила:

Обычный массив имеет глубину 1.

Каждый уровень вложенного массива увеличивает глубину на 1.

Пустой массив имеет глубину 1.

Массив с числами, но без вложенных массивов, тоже имеет глубину 1.

Примеры:

getDepth([1, 2, 3]);
// 1

getDepth([1, [2, 3], 4]);
// 2

getDepth([1, [2, [3, 4]], 5]);
// 3

getDepth([[[]]]);
// 3

getDepth([]);
// 1

Условия: без циклов, map(), filter(), reduce() и сторонних библиотек.

Здесь важно самостоятельно определить, что должна возвращать функция для каждого вложенного массива и как из этих результатов получить максимальную глубину всей структуры.
